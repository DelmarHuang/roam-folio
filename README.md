# Folio · 书页集 · 1.4.21

代码块工具会随新展开的笔记自动出现。搜索会保留当前块的查询词与匹配位置；支持替换当前项或一次替换当前代码块中的全部匹配，使用编辑器原生事务并保留撤销能力。搜索为不区分大小写的字面匹配。

顶栏设置面板可拖动标题栏移动，打开时仍能操作页面，便于边切换设置边观察变化。

顶栏的滑杆按钮可打开全部 Folio 设置，设置页和弹窗顶部均可隐藏或重新开启该入口。原生 AI 入口位于主顶栏，聊天仍保留在右侧边栏；The Desk 搜索图标已调整为避开边框。

Folio 为 Roam 带来温暖的杂志式排版，将标签、旁注、日历、阅读和任务工具整合在一起。小组件可独立启停，让记录更清晰、阅读更专注。

**更多独立插件**

- **Reading Desk** — 把阅读、批注与思考汇聚一处，让读过的内容真正留下来。
- **Version Studio** — 对比笔记的不同版本，追踪思路变化，放心改写每一个想法。

两款插件单独下载、独立安装，不包含在 Folio 中。

## 安装

1. 停用旧版杂志风 `roam/css` 和相关 `roam/js`，避免重复加载。
2. 解压 ZIP。
3. 打开 Settings → Roam Depot → Developer Mode → Load unpacked extension。
4. 选择直接包含 `extension.js` 的目录。
5. 在 Extension Settings → Folio 中选择语言并调整开关。Auto 跟随浏览器语言。

## 主题与组件

主题由一个总开关控制；关闭主题后，已启用的组件继续适配 Roam 原生配色。29 个组件按功能分为七组，左侧导航切换分组；每个组件旁标注原有的资源消耗等级，均可独立启停。外观、标签名称、代码高度和导航快捷键保留在对应功能区。资源等级是估计，不是实时 CPU 占用。

- 界面与导航: 固定显示原生侧栏开关, 隐藏顶部图标, 隐藏左侧边栏项目, Workbench 下拉选择兼容, 仅在滚动时显示页面滚动条, 页面关系图按钮, 右侧栏卡片.
- 标签与内容: 特殊标签与印章, OR 勾叉下拉, 属性资料卡, 按引用次数调整版面权重.
- 写作与代码: 打字机模式与写作目标, 页边旁注, 限制代码块高度, 代码块操作工具.
- 日记与日历: 日记刊头, 日历快捷操作, 日历键盘导航, 自动日记模板, 日期热度与预览, 处理昨日遗留 TODO, 日历快速记录.
- 阅读与媒体: 图片与图注, PDF 窗口, 视频阅读器.
- 页面洞察: 页面数据行, 页面脉搏.
- 任务与回顾: 编辑部案头, 随机任务 3.

新安装默认启用主题与组件。关闭组件会清理其运行资源。“临时停用 Folio（排查冲突）”用于和原生界面对照。

## Random TODO 3 · 排除设置

在“任务与回顾”中设置：排除页面默认填入 `SmartBlock` 和 `roam/templates`；每行一个完整页面名，可修改或继续添加。按任务所在页面精确匹配，包含该页面下各层子块，不会因为正文只是引用该页面就排除任务。

“排除带未来日期的 TODO”默认开启；关闭后，正文中明确链接未来日记日期的任务也可参与抽取。设置即时生效并保存；空的排除列表和关闭状态也会保留。恢复默认设置会恢复上述两个页面和开启状态。规则仅过滤抽取候选，不修改原任务。

## 字体、座右铭与标签

字体填写已安装字体的 CSS `font-family`，不是字体文件或网址；留空恢复默认字体链。座右铭最多两行，每行预算 24：英文计 1，中文、全角字符及表情计 2，并按侧栏实际宽度进一步限制。

标签名称可在设置中修改，切换界面语言不会改写 Roam 页面名。笔记类型与 Reading List 的 `[[双链]]` 和 `#标签` 使用相同的 **12px** 字号，与 Q1 印章一致；不再随正文字号放大。人物、行业标签仍跟随正文大小。书名、人物、行业、motive、rediscover 保留原生链接点击。

## 使用要点

- 视频工具栏 Open 在右栏打开视频块；Timestamp、Theater、Notes 沿用既有处理。视频源码还包含影院时间戳笔记的编辑与删除功能。
- 子块加 `#.aside` 或 `#.aside-left` 可显示右侧或左侧旁注，也可用圆点右键菜单操作；空间不足时留在正文。评论侧轨不启用。
- PDF 全屏提供退出链接与 Esc 返回。代码高度默认 420px，0 表示不限制；高度限制可独立关闭。
- Query/Data Table 使用原生列宽调整。块菜单和命令列表间距由 Roam 管理。
- 正文保留一层居中；块内分隔区为 8px，引用计数保留。Roam 原生左栏宽度为 232px，本插件没有另加左栏拖宽功能。
- 导航快捷键默认 G 跳转日期、T 今天、D 日记流、左右箭头前后一天；可自定义，编辑文字时不触发。
- 随机 TODO 3 默认排除带明确未来日记日期的任务（可关闭），避免重复追加已有的来源链接。纸张老化、mark it 及其设置已删除。

日历图标与 Alt＋点击日期引用使用相同的增强布局；引用日期的选择仍由 Roam 原生处理。日期预览在光标移出时立即消失，关闭日历或窗口失焦时也会清理。

## 开发与验证

运行 `npm run build` 和 `npm run check`。可选 `npm run check:layout`、`npm run check:interaction` 需要 Playwright/Chromium；可用 `FOLIO_TEST_CHROMIUM` 指定浏览器。`FOLIO_DOM_FIXTURE` 可指定导出的 DOM。成品为 `extension.js`，源码位于 `src/` 和 `source/`。

验证范围见 [TEST-REPORT.md](TEST-REPORT.md)，版本记录见 [CHANGELOG.md](CHANGELOG.md)。本地渲染与 API 替身测试不等于用户已登录图谱中的全面验收。

# Folio · 书页集

**为 Roam 带来杂志式排版，以及一组可以独立使用的日常工具。**

我希望自己的 Roam 是一个愿意每天打开、能够长时间阅读和写作的地方。Folio 围绕这个想法，将温暖的纸张配色、清晰的标题层次、页边留白与日常使用的小工具整理在一起，让笔记呈现出更接近杂志和书页的阅读感。

除了正文，Folio 也协调了日记、侧栏、标签、属性内容，以及部分社区插件的界面，并对 Roam 的 AI 入口和 The Desk 做了样式适配，让不同工作区域保持连贯的视觉风格。

主题与工具组件可以分别控制。喜欢杂志式排版，可以开启主题；希望沿用其他外观，也可以单独选择需要的小工具。

## 把右侧栏变成并排的工作空间

右侧栏是 Folio 最重要的工作区域之一。

阅读或写作时，我们经常需要同时打开几份材料：一篇原文、一条相关笔记、一段正在整理的想法。Folio 把右侧栏中的内容排列成可以横向浏览的卡片，让它们与主页面并排展开。

每张卡片保留自己的滚动区域和原生操作。你可以在卡片间来回查看，展开、折叠或关闭其中一张，同时继续阅读正文。

Roam 原生 AI 的入口也放在主顶栏，聊天继续留在右侧卡片中。历史记录、话题与新建操作跟随聊天卡片排列，方便一边看笔记，一边提问和整理。

## 让补充说明找到合适的位置

页边旁注是我特别重视的功能。

在写作中，有些子块是正文的一部分，有些只是例子、补充说明或临时想到的另一条线索。我希望能逐块决定它们的位置，让主要论述保持连贯，同时把值得保留的补充内容放在附近。

Folio 可以把选中的子块放到正文左侧或右侧：

- 在块圆点的右键菜单中选择 **Aside: Left** 或 **Aside: Right**。
- 或者给子块添加 `#.aside-left` 或 `#.aside`。
- 其他子块继续保持正常的大纲结构；页边空间不足时，旁注会留在正文中显示。

例如，可以把一个关键问题放在左边，把解释或例子放在右边，正文则继续展开主要论证。旁注会跟随 Roam 原生页面宽度和侧栏空间调整。

## 一边看视频，一边留下想法

视频中的一个观点，往往值得马上记下来。Folio 的影院模式把视频与时间戳笔记放在同一个主页面中，让观看、记录和回看连在一起。

点击 **Timestamp**，通过 Roam 原生评论机制添加带时间戳的笔记。Folio 将这些评论同步展示在视频下方，点击时间戳即可返回对应片段；文字可以直接修改、保存或删除，编辑保存回同一条评论。**Open** 可以在右侧栏查看原始块。

在较小的窗口里，视频会限制高度，给笔记留出空间；大窗口则保留两侧留白，让视频与笔记对齐。这样，回顾一段访谈、讲座或课程时，可以沿着自己的笔记快速找到值得重看的部分。

## 让反复使用的想法更醒目

有些段落会被不断引用，逐渐成为多个页面之间的重要连接。Folio 可以根据块的引用次数调整版面权重，让被频繁使用的内容以更醒目的字号呈现。

在演示页面中，不同段落建立了不同数量的真实块引用，可以直观看到字号与视觉强调的变化。这项功能能够独立开关，也保留原有的引用计数和跳转方式。

## 把日常操作放到顺手的位置

Folio 还包含一组可独立启用的组件，覆盖写作、导航、阅读和回顾：

- **写作与代码**：打字机模式与写作目标；代码块高度限制、首尾跳转、复制、搜索，以及替换当前项或全部匹配。新展开的代码块会自动出现工具，搜索会记住当前块的位置。
- **日记与日历**：杂志式日记刊头；日期导航、活动热度、日记预览和快速记录；昨日遗留 TODO 处理、自定义快捷键，以及可配置的日记模板。
- **阅读与媒体**：图片与图注样式、PDF 扩展阅读视图，以及视频影院视图和时间戳笔记。
- **标签与页面信息**：特殊标签与印章、OR 勾叉下拉、属性资料卡，以及按引用次数调整的视觉权重；页面数据行显示字数和预计阅读时间，页面脉搏呈现近期被提及的情况。
- **界面与导航**：顶部图标和左侧栏项目的显示控制、侧栏开关、页面关系图入口、滚动条显示，以及 Workbench 下拉兼容和右侧栏卡片。
- **任务与回顾**：The Desk 的九种排序、类型筛选、多卡片置顶与头条选择；Random TODO 3 帮助重新发现待办，可排除指定页面和带未来日期的任务。
- **外观设置**：正文、标题与旁注字体，以及两行座右铭。

全部 **29 个组件**按七类功能组织，可分别启停，并标注估计资源消耗等级。顶部设置面板可以拖动位置，调整时仍能操作页面，便于边使用、边找到适合自己的组合。

提供英语、中文、意大利语、德语、法语和西班牙语的界面翻译及说明文档。完整组件列表、详细功能与操作请查看 [Folio 的 GitHub 页面](https://github.com/DelmarHuang/roam-folio)。

还可以搭配两个独立插件：**Reading Desk** 把阅读、批注与思考汇聚一处；**Version Studio** 帮你对比笔记版本，追踪思路变化，放心改写。
